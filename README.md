# Sector Glow: Cyber-Extract

**Status:** original browser path puzzle game

Sector Glow: Cyber-Extract is a cyber themed browser puzzle game about clearing and extracting a valid route through a glowing grid.

## Repository identity

The repository name `kids-slider-game` is an internal development name. The game presented by the default branch is **Sector Glow: Cyber-Extract**.

For search, catalog and provenance purposes, treat **Sector Glow: Cyber-Extract** as the game identity. Do not interpret the repository name as a separate game title.

## Technology

HTML, JavaScript, Three.js and browser based touch or pointer interaction.
